# Plex Apps

Plex is available on almost every platform. Here's where to get it and how to get the best experience.

## Where to Download

- **iOS / iPadOS** — [App Store](https://apps.apple.com/app/plex/id383457673)
- **Android** — [Google Play](https://play.google.com/store/apps/details?id=com.plexapp.android)
- **Apple TV** — Available in the App Store on your Apple TV
- **Roku** — Available in the Roku Channel Store
- **Fire TV** — Available in the Amazon Appstore
- **Smart TVs** — Most Samsung, LG, and Vizio TVs have Plex built in
- **Web** — Use [app.plex.tv](https://app.plex.tv) in any browser
- **Desktop** — Download from [plex.tv/media-server-downloads](https://www.plex.tv/media-server-downloads/#plex-app)

## Recommended Settings

For the best streaming experience:

### Video Quality
- **Home network**: Set to **Maximum** or **Original** quality to avoid unnecessary transcoding
- **Away from home**: Start with **720p 4 Mbps** and increase if your connection supports it

### Subtitles
- If you prefer subtitles, set them to **Auto** so they only show when the audio is in a different language

### Audio
- If you have a soundbar or surround system, make sure the app is set to pass through the original audio format

## Plex Pass

You don't need a Plex Pass to use the server. A free Plex account is all that's required. However, if you want features like downloads for offline viewing on mobile, that requires a Plex Pass on your own account.
