# Getting Started

Welcome to the Media Center! This is your hub for everything related to Jory's Plex media server. Here you'll find guides on how to use the services available to you.

## What's Available

- **Plex** — The main media server where you can stream movies, TV shows, and music.
- **Seerr** — A request tool that lets you browse and request new movies and TV shows to be added to the server.

## How It Works

All the media is hosted on a personal server and shared with friends and family through Plex. You've already signed in with your Plex account, which means you have access to the server.

From here you can:

1. **Stream content** directly through the Plex app on your preferred device
2. **Request new content** through Seerr if there's something you'd like to watch
3. **Browse these docs** for tips on getting the best experience

## Need Help?

If you run into any issues, reach out to Jory directly.
